# Security Policy — VoidXHub v3

## Principles

- Never commit secrets
- Least privilege for all roles
- Short-lived access for downloads
- Full audit trail for admin actions
- Input validation on every endpoint

## Reporting a Vulnerability

Email: voidxhub.security@gmail.com  
Telegram: @YASHXCHI or @VOIDXHUB_ADMIN

Please include:
- Type of issue
- Steps to reproduce
- Impact
- Suggested fix (optional)

## Response Targets

- Critical (payment bypass, admin access): within 24 hours
- High: within 48 hours
- Medium/Low: within 7 days

## Scope

In scope:
- Authentication & session handling
- Payment flows
- Key / license generation
- File delivery endpoints
- Admin panel

Out of scope:
- Social engineering
- Physical attacks
- DDoS
